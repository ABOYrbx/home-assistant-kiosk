# Code of Conduct

This is a small project with a simple rule: be respectful and assume good faith.

## Expected behaviour

- Use welcoming and inclusive language.
- Respect different experience levels and viewpoints.
- Give technical criticism about the work, not the person.
- Accept correction and correct mistakes openly.
- Keep discussions focused on the project.
- Protect privacy: do not publish tokens, addresses, personal entity IDs, or private logs.

## Unacceptable behaviour

- Harassment, threats, discrimination, or personal attacks.
- Sexualized language or imagery.
- Publishing another person's private information without permission.
- Deliberately disruptive behaviour, spam, or bad-faith arguments.
- Ignoring a maintainer's request to stop a behaviour.

## Scope

This applies to issues, pull requests, discussions, code review, and any project space. It also applies when representing the project elsewhere.

## Reporting

Report a conduct issue privately to the maintainer, `@ABOYrbx`, through GitHub. If the report also involves a security issue, use the private security advisory described in [`SECURITY.md`](SECURITY.md).

Do not open a public issue about a conduct report.

## Enforcement

The maintainer may edit or remove content, close threads, or block participation. Enforcement is proportional to the behaviour and focused on keeping the project usable. There is no formal committee for a project of this size.
